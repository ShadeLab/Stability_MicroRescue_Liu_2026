# GitHub Repository for
# Microbial activity transitions underlie community stability following persistent warming
By Xipeng Liu, A. Fina Bintarti, Margaux Buron, Milena Gonzalo, Ashley Shade*

Université Lyon 1, CNRS, INRAE, LEM, UMR 5557, Villeurbanne, France

*Correspondence to Ashley Shade: ashley.shade@cnrs.fr

## Data and code
The sequence data generated in this study have been deposited in the NCBI Sequence Read Archive under BioProject number PRJNA1554522.

Microscope images for total- and active- cell abundance, and redox activity are available on FigShare (https://doi.org/10.6084/m9.figshare.34768650). Code for automated image processing is available (https://github.com/DatInsights-com/process_quantom).
